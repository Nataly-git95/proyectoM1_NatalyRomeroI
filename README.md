# 🎨Generador de paletas de colores #
Aplicación web para generar paletas de colores aleatorias en formatos HEX, RGBA y HSL.

## 📌Instrucciones de uso - manual de usuario

1. Seleccionar la cantidad de colores.
2. Seleccionar el formato del color:
   * HEX
   * RGBA
   * HSL
3. Presionar el botón: crear paleta
4. La aplicación generará automáticamente una nueva paleta.
5. Usar el botón 🔒 para bloquear colores.
6. Los colores bloqueados no cambian al generar otra paleta.

## ⚙️Decisiones técnicas - Manual técnico
### Tecnologías utilizadas
  * HTML5
  * CSS3
  * JavaScript Vanilla

## Decisiones tomadas
  * Uso de HTML semántico para mejorar estructura y accesibilidad.
  * Uso de CSS Grid y Flexbox para diseño responsive.
  * Uso de JavaScript Vanilla para practicar lógica y manipulación del DOM.
  * Render dinámico de tarjetas mediante createElement().
  * Uso de arrays y objetos para manejar estados de colores bloqueados.
  * Contraste automático del texto para mejorar legibilidad.
  * Toast notifications para mejorar experiencia de usuario.

## 💻 Pasos para descargar y ejecutar en local

### 1. Descargar el proyecto

Clonar el repositorio:
```
git clone URL_DEL_REPOSITORIO
```

o descargar el archivo .zip.

### 2. Abrir el proyecto

Abrir la carpeta en Visual Studio Code.

### 3. Ejecutar la aplicación

Abrir el archivo:
```
index.html
```
con Live Server o directamente en el navegador.

## 🌐 Pasos para desplegar en GitHub Pages

### 1. Crear repositorio en GitHub

Subir los archivos del proyecto.

### 2. Ir a configuración

Entrar a:
```
Settings → Pages
```
### 3. Configurar Pages

Seleccionar:
```
Branch: main
Folder: /root
```
Guardar cambios.

### 4. Abrir la URL generada

GitHub Pages generará automáticamente un enlace público para la aplicación.
